# Audit Results

Dated reports produced by running the audits in `../schedule/`.

Rules:

- File naming: `YYYY-MM-DD-{audit-name}.md` (e.g. `2027-03-01-security-review.md`).
- Reports are point-in-time snapshots — never edited after being saved.
- Every actionable finding in a report gets a backlog ticket (`../backlog/`); the report records *what was found*, tickets track *what gets fixed*.
- This README stays; it is not a report.
