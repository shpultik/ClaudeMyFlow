# Done

Completed and verified tickets. `REJECTED` tickets also live here (with the rejection reason recorded in the ticket).

Rules:

- A ticket may only move here after its acceptance criteria are met **and the implementing changes are committed** to git. Finished but uncommitted → keep it in `../inbox/` with status `ready to commit`.
- Every move here includes adding a row to the "Done" table in `../backlog/README.md`.
- Each completed feature also gets an entry in `../documentation/features/`.
- This README stays; it is not a ticket.
