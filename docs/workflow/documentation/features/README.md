# Feature Changelog

One file per feature area, recording **done work only**: what shipped, when, which tickets, key decisions. New entry (or appended section) every time a ticket moves to `../done/`.

Naming: `{kebab-feature-name}.md` (e.g. `push-notifications.md`).

Each entry records:

- What changed, in behavior terms
- Version shipped in (if the project versions)
- Ticket link(s)
- Non-obvious decisions and their reasons
