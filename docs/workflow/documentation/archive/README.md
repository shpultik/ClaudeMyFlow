# Archive

Point-in-time snapshots: audit baselines, one-off deep reviews, superseded plans.

Rules:

- Filename includes a date: `{TOPIC}_{YYYY_MM_DD}.md` or similar.
- **Never edited** after a file is placed here. If reality changes, write a new snapshot or update the living docs — don't touch the old file.
- Living docs may link here for history, but current-state claims belong in `../state/` and `../reference/`.
