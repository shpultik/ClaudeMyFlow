# Memory Seed

Pre-written memory files distilled from real agent-driven development — the lessons that were learned the hard way once, so new projects don't relearn them.

**Consumed by SETUP.md Step 6:** if the agent has a persistent memory directory, each file here is copied into it and indexed in `MEMORY.md`; then this whole folder is deleted from the repo. If the agent has no memory system, the folder is simply deleted — the same rules exist in condensed form in CLAUDE.md's "Working Rules" section.

Notes:

- `solo-dev-commit-to-master.md` assumes a single-developer project — confirm before seeding; skip for team projects.
- These are starting points. The new project's memory should grow its own project-specific facts on top.
